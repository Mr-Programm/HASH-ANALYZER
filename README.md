This is a program used to take a users input data, and then hash data to identify possible HASH methods that where used to in its hashing method.

This should identify 'md5', 'sha1', 'sha224', 'sha256', 'sha384', 'sha512', 'sha3_224', 'sha3_256', 'sha3_384', 'sha3_512', 'blake2b', 'blake2s' hashing methods.
